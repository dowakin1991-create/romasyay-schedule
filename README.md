# Ромасяй Графік

Окремий застосунок графіка працівників, перенесений із `dowakin1991-create/Menu_kabinet`. Оригінальні «Ромасяй» та «Кабінет Графік» не змінені.

## Сторінки
- `index.html` — графік працівників, побажання вихідних, обліковий запис і статистика
- `admin.html` — керування графіком, змінами, працівниками, подіями, експортом
- `assets/romasyay-icon.svg` — окрема іконка для застосунку та його інтерфейсу

## Firebase — обов'язкові кроки перед запуском
1. Використовується наявний Firebase-проєкт **romasyay-cloud**. Графік звертається до **Cloud Firestore**, а застосунок інвентаризації використовує **Realtime Database** (`inventories`). Ці два сховища не слід плутати.
2. У Firebase Console увімкніть **Authentication → Email/Password**, а для гостьового перегляду, за необхідності, **Anonymous**. Переконайтеся, що Cloud Firestore створений і доступний.
3. У `js/config.js` встановіть `ADMIN_UID` за **перевіреним Firebase Authentication UID власника**. Наразі він навмисно порожній, щоб не переносити права адміністратора «Кабінету».
4. У `firestore.rules` замініть `REPLACE_WITH_ROMASYAY_OWNER_UID` на той самий UID і перевірте всі правила. **Не публікуйте файл без злиття з чинними правилами Firestore**: розгортання замінить правила для всього Firestore-проєкту.
5. `js/push-config.js` навмисно не містить URL Cloudflare Worker від «Кабінету». Для push-сповіщень слід окремо налаштувати свій бекенд та підписки.
6. Перевірте вхід, роль власника, побажання, повні й половинні зміни, події, збереження, експорт та браузери Android / Chrome / iPhone, перш ніж публікувати головну гілку.

**Статус:** код перенесено в окрему гілку на перевірку. Перенесення вихідного коду **не налаштовує автоматично** Firebase Auth, Firestore Rules або push-сервіс. Приватність GitHub-репозиторію сама по собі не захищає опублікований сайт.
