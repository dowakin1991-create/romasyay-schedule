🔔 Ромасяй Графік — VAPID-ключі

Ключі генеруються лише у твоєму браузері засобами Web Crypto. Ця сторінка не надсилає їх на сервер і не зберігає після закриття.

Згенеруй одну пару лише для «Ромасяй Графік». Не використовуй ключі «Кабінету». Після запуску push не створюй нову пару без необхідності: старі підписки перестануть працювати.

Cloudflare → Worker romasyay-schedule-push → Settings → Runtime variables and secrets → Add variable. Назва VAPID_JSON, позначка Secret, Production. Встав текст із поля вище у Value, потім натисни «Add variable and deploy». Не надсилай секрет у чат і не додавай до GitHub.

Цей ключ знадобиться для перевірки конфігурації. Приватний ключ публікувати не можна.
